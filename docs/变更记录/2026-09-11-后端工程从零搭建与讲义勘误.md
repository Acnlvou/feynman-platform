## 8. 关键约定

- **本地 Git + 压缩包分发**：仅本地用 git，分发时排除 `node_modules/` 与 `.env`（含数据库密码、`JWT_SECRET`、API Key，绝不外泄）
  - 推荐：`git archive --format=zip -o ../feynman-backend.zip HEAD`（自动遵守 .gitignore）
  - 要带历史：`git bundle create feynman-backend.bundle --all`
- **Atlas 连接串**：从 Connect → Drivers → Node.js 复制后要改 3 处
  1. `<db_password>` → 真实密码（去尖括号）
  2. 数据库用户名 → 自己建的用户名
  3. `.net/` 后补上 `/feynman-db`
- **密码特殊字符**：含 `@ : / ? # &` 必须 URL 编码；推荐用 Autogenerate 的纯字母数字密码
- **认证头**：固定使用 `x-auth-token`，Postman 演示截图也按此对齐
