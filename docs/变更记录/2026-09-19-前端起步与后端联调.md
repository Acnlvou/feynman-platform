# 2026-09-19 · 前端起步与后端联调

> 文档类型：变更记录
> 关联项目：费曼学习平台（《大前端与 AI 实战》64 学时实训课）

## 1. 本次目标

在 `front/` 中初始化 React + Vite 前端工程，完成第 4 次课的页面骨架，并落地第 5 次课的认证状态与基础 API 联调。

## 2. 已完成内容

- 使用 React + Vite 建立前端工程。
- 使用 `react-router-dom` 配置登录、注册、学习概览和知识点页面。
- 使用 React Context + `localStorage` 保存 JWT 登录状态。
- 增加路由守卫，未登录用户不能访问学习空间。
- 使用 Axios 封装 API 客户端，自动发送 `x-auth-token`。
- 对接后端接口：
  - `POST /api/users/register`
  - `POST /api/users/login`
  - `GET /api/knowledge-points`
  - `POST /api/knowledge-points`
  - `DELETE /api/knowledge-points/:id`
- 完成知识点搜索、状态显示、创建和删除。
- 增加响应式布局与中文界面样式。

## 3. 启动方式

前端：

```bash
cd front
npm install
npm run dev
```

后端需在另一个终端启动：

```bash
cd backend
npm start
```

前端默认请求 `http://localhost:3000/api`，可通过 `front/.env.local` 中的 `VITE_API_BASE_URL` 修改。

## 4. 验证结果

- `npm run build`：通过。
- Vite 开发服务器：可访问 `http://localhost:5173/`。
- 后端根路由：可访问 `http://localhost:3000/`。
- 注册接口请求已到达后端；当前测试环境的后端进程未读取可用 MongoDB 连接，因此返回数据库未连接提示。前端代码和 API 请求链路已接通，真实注册/登录需先确认后端进程使用正确的 `backend/.env` 并成功连接 Atlas。
