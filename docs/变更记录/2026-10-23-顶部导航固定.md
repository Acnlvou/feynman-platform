# 2026-10-23 顶部导航固定

知识库与学习概览原先采用普通文档流，滚动长页面时导航会离开视口。本次将共享 `.topbar` 设置为 sticky、top:0，并设置层级和禁止收缩，保持原有紧凑高度与导航位置。内容从导航下方滚动，导航和账号菜单持续可用。编辑与详情仍沿用固定视口、正文内部滚动布局。

实际浏览器使用现有测试账号，只读检查知识库与概览，未修改数据库。390×500的知识库滚动97.5px、1024×320的概览滚动150.5px后，导航矩形顶部仍为0；滚动后账号菜单可打开，导航可切换页面。前端生产构建和git diff --check通过。本次为共享样式修复，未运行后端测试或整套业务回归。

## 修正：固定工作台，取消整页滚动

用户复核后指出吸附导航仍留下整页滚动。本次改为app-shell固定100dvh且overflow:hidden，主内容区flex:1、min-height:0、overflow:auto，滚动限定在顶部导航下方；隐藏工作台装饰页脚，保留更多内容空间。编辑与详情已有的内部滚动覆盖规则继续生效。

390×500实测：文档高度500、window.scrollY为0、顶部位置0；主内容区高度443、内容高度487、内部scrollTop为44。确认滚动发生在main内，整个页面无滚动。此前sticky方案的验证仅证明吸附，不作为取消整页滚动的证据。
