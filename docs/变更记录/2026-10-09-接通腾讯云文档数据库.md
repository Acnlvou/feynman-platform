# 2026-10-09 · 接通腾讯云文档数据库

原 Atlas 连接未能用于本地项目，本次将后端持久存储切换为腾讯云 CloudBase 文档数据库。Express 路由、前端 API 地址及 JWT 请求头保持一致。

## 完成内容

- 接入 `@cloudbase/js-sdk`，数据库集合为 `users` 和 `knowledge_points`。
- 后端配置固定读取 `backend/.env`；真实服务端 Key 只存于被 Git 忽略的该文件。
- 用户密码继续使用 bcrypt 哈希；知识点继续检查用户归属、状态及输入类型。
- 适配 CloudBase 新增记录返回的 `id`，对外仍提供 `_id`；不存在的记录返回 404。
- 知识点列表分批读取，避免数据库默认查询条数导致列表被截断。
- 增加根目录 `启动项目.command`，同时启动前后端，Ctrl+C 清理两个服务；本机使用已有可用的 Node.js 运行时。

## 验证结果

- 真实云数据库：注册、重复注册拦截、登录、错误密码拦截通过。
- HTTP 接口：知识点创建、列表、详情、更新、删除通过；未登录返回 401，跨用户访问/修改返回 403，无效状态返回 400，删除后查询返回 404。
- 停止后端进程并重新启动，仍可登录并读回已更新的知识点，确认远程持久化。
- 使用 101 条临时知识点验证跨页读取，全部返回且没有重复，随后移除测试数据。
- 前端生产构建通过；启动脚本可启动两项服务，Ctrl+C 后 3000 和 5173 端口均释放。
- 临时测试用户和知识点已移除，不保留测试账号。

## 使用

双击根目录 `启动项目.command`，打开 <http://127.0.0.1:5173/>。首次在新电脑配置时，按照后端说明准备依赖和 `backend/.env`。
