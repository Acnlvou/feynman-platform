# 2026-09-18 · 项目目录统一与根仓库建立

> 文档类型：变更记录
> 关联项目：费曼学习平台（《大前端与 AI 实战》64 学时实训课）

---

## 1. 本次目标

将后端工程、课程讲义、项目计划、技术说明、变更记录和参考材料统一收纳到 `feynman-platform/`，并由项目根目录的单一 Git 仓库进行版本控制。

## 2. 目录调整

```text
feynman-platform/
├── backend/                  # 原后端工程；移除嵌套 .git，纳入根仓库
├── front/                    # 后续前端代码目录
└── docs/
    ├── 课程讲义/              # 《大前端与 AI 实战》第 1–6 次课讲义
    ├── 项目计划/              # 全项目路线图、阶段实现计划
    ├── 技术文档/              # 后端 README、讲义勘误
    ├── 变更记录/              # 项目变更记录
    └── 参考资料/幻灯片/        # PPT 与课程参考材料
```

## 3. 具体变更

- 建立项目根目录 `feynman-platform/` 的统一 `.gitignore`。
- 将原后端工程保留为 `feynman-platform/backend/`，删除其嵌套 Git 元数据，避免形成 Git 仓库嵌套。
- 将第 1–6 次课讲义迁移到 `docs/课程讲义/`。
- 将全项目执行计划和第 1–3 课后端实现计划迁移到 `docs/项目计划/`。
- 将后端工程说明和勘误文档迁移到 `docs/技术文档/`。
- 将历史后端搭建记录迁移到 `docs/变更记录/`，并修正旧路径引用。
- 将 PPT 参考材料统一放入 `docs/参考资料/幻灯片/`。
- 新增根目录 `README.md` 与 `docs/README.md`，提供项目入口和文档导航。
- 后端 `package.json` 标记为 `private: true`，避免被误当作公开包发布。

## 4. 版本控制约定

- 根仓库路径：`feynman-platform/.git/`
- 后续代码、文档和计划变更均在根仓库提交。
- 不跟踪 `**/node_modules/`、`**/.env`、构建产物和系统元数据。
- 保留 `backend/.env.example` 作为配置模板，不提交真实密钥。
