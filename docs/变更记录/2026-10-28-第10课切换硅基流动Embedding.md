# 第10课：切换硅基流动 Embedding

## 变更内容

按用户选择，将第10课的向量适配从百度千帆切换为硅基流动 `BAAI/bge-m3`。服务端请求地址为 `https://api.siliconflow.cn/v1/embeddings`，使用 `Authorization: Bearer ...`，请求体仍为 `{model,input}`；输入可批量传字符串数组。使用独立配置项 `SILICONFLOW_EMBEDDING_MODEL`，不与生成模型的 `SILICONFLOW_MODEL` 混用。模型最大输入长度依照当前官方文档为8192 tokens；课程分块仍保持每块最多500字、重叠50字。

适配文件改名为 `backend/services/siliconflowEmbeddings.js`。它复用后端 `SILICONFLOW_API_KEY`，请求超时、响应大小、向量维数和错误安全处理继续保留。HNSW 索引路径、状态、自动重建和本人权限规则不变；切换模型名后，已有旧模型索引会被视为过期并在单条/全部重建时重新生成。

## 配置

在被 Git 忽略的 `backend/.env` 中配置硅基流动 API Key 和模型 ID：

```dotenv
SILICONFLOW_API_KEY=
SILICONFLOW_EMBEDDING_MODEL=BAAI/bge-m3
```

若 `SILICONFLOW_API_KEY` 已配置为同一个硅基流动账号的 Key，可以继续复用；不要把 Key 发到聊天、写进前端或提交到仓库。本次没有读取或修改真实 `.env`。

官方依据：[Embedding API](https://api-docs.siliconflow.cn/docs/api/embeddings-post)、[创建 API Key 快速上手](https://docs.siliconflow.cn/docs/userguide/quickstart)。
