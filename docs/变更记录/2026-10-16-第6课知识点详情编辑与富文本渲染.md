# 2026-10-16 · 第 6 课：知识点详情、编辑与富文本渲染

对照讲义第 6 次课《知识点模块与富文本渲染》的作业要求补齐前端缺口：此前只有列表、搜索、新建和删除，缺少“查看”和“编辑”，也没有任何 Rich Text 渲染能力。本次完成基础要求与进阶要求（LaTeX、Mermaid），挑战要求未做。

## 完成内容

- 新增 `front/src/pages/KnowledgeDetailPage.jsx`：查看单个知识点，渲染正文，区分 404 不存在、403 无权访问与其他错误；提供编辑、删除、返回列表入口。
- 新增 `front/src/pages/KnowledgeEditPage.jsx`：加载已有内容回填表单，保存后回到详情页并提示“知识点已更新”。
- 新增 `front/src/components/KnowledgePointForm.jsx`：新建与编辑共用同一表单，带「编辑 / 预览」切换，预览使用真实渲染器。
- 新增 `front/src/components/MarkdownContent.jsx`、`MarkdownRenderer.jsx`、`MermaidChart.jsx`：
  - `react-markdown` + `remark-gfm`：Markdown 与 GFM（表格、任务列表、删除线）
  - `remark-math` + `rehype-katex` + `katex`：行内与块级 LaTeX 公式
  - `mermaid`：`language-mermaid` 代码块渲染为 SVG，语法错误时显示失败原因并回显源码，不牵连整页
  - 渲染异常由错误边界兜底，只降级该段富文本
  - 富文本引擎与 `mermaid` 均按需加载（`React.lazy` / 动态 `import()`）
- `front/src/pages/KnowledgePage.jsx`：标题链接到详情、增加编辑入口、显示待复习标记、列表摘要去掉原始 Markdown 围栏。
- `front/src/App.jsx`：新增 `/knowledge/:id` 与 `/knowledge/:id/edit` 路由，均位于登录保护内。
- `front/src/index.css`：追加详情、编辑、富文本与图表样式，未改动既有规则。
- 依赖：`react-markdown@10.1.0`、`remark-gfm@4.0.1`、`remark-math@6.0.0`、`rehype-katex@7.0.1`、`katex@0.16.47`、`mermaid@12.2.0`。

`katex` 显式安装为 0.16.47：`npm install katex` 默认解析到 0.19.0，而 `rehype-katex@7` 依赖 `katex@^0.16`，版本错开会导致公式标记与样式表不匹配。

## 使用

前端在 `front/` 运行 `npm run dev`，或使用根目录 `启动项目.command`。知识点正文按 Markdown 书写，`$...$` 与 `$$...$$` 写公式，```` ```mermaid ```` 代码块写图表。
