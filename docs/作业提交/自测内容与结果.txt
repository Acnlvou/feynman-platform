二、自测题目与答案

1. 登录页面提交时，前端做了哪些事情？
答：阻止表单默认提交，清空旧错误，设置 submitting 状态，然后调用 AuthContext 的 login 方法；请求完成后恢复按钮状态。失败时显示错误，成功时跳转到学习空间。

2. 登录请求具体调用了哪个接口？
答：前端通过 apiClient.post('/users/login', credentials) 调用后端接口，结合 baseURL 后完整地址是 POST /api/users/login。

3. 登录成功后 Token 保存在哪里？
答：后端返回 response.data.data.token，AuthContext 将它保存到 localStorage 的 feynman_token，同时更新 React 状态。

4. 为什么要使用 React Context 管理登录状态？
答：登录状态会被多个页面和组件使用。使用 Context 后，LoginPage、路由守卫、导航栏和业务页面可以共享 token、user、login、logout，不需要层层传递 Props。

5. Axios 请求拦截器的作用是什么？
答：每次发送请求前从 localStorage 读取 feynman_token；如果存在，就自动添加 x-auth-token 请求头，使后端能够识别当前登录用户。

6. ProtectedRoute 如何保护页面？
答：它从 AuthContext 获取 isAuthenticated。如果没有 Token，就使用 Navigate 跳转到 /login；有 Token 时通过 Outlet 渲染受保护的学习空间页面。

7. 如果登录请求失败，页面会如何处理？
答：catch 捕获请求错误，通过 getApiErrorMessage 读取后端 message、error 或网络错误，并在表单上显示提示；finally 中恢复提交按钮状态。
