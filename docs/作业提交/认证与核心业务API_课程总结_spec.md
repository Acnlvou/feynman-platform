## 页面结构
1. 封面：标题“让页面真正登录”，副标题“前后端联调与登录页实现”，点明 React + Axios + JWT。
2. 本次完成什么：两项主成果——登录页前端、API 联调；底部列出实际涉及的文件。
3. 登录页前端：展示真实页面结构和交互：邮箱、密码、提交中状态、错误提示、注册入口；对应 LoginPage.jsx。
4. 一次登录请求：LoginPage → AuthContext.login → apiClient.post('/users/login') → 后端 → data.token → localStorage → 跳转；强调请求链已接通。
5. 登录状态保持：AuthContext、localStorage、Axios 请求拦截器、ProtectedRoute 四个部件如何协作。
6. 联调验证结果：前端 npm run build 通过、Vite 与后端地址可访问、请求能够到达后端；真实注册/登录待配置 MongoDB。
7. 课程成果与下一步：已完成 / 待完成双栏；结论是前端登录骨架与请求链完成，下一步接入可用数据库完成真实登录验收。
