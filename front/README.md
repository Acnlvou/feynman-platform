# 费曼学习平台前端

React + Vite 前端工程，位于项目根目录的 `front/`。

## 当前功能

- React + Vite 基础工程
- `react-router-dom` 客户端路由
- 登录、注册页面
- React Context + `localStorage` 登录状态
- 路由守卫：未登录时不能访问学习空间
- Axios API 客户端，自动携带 `x-auth-token`
- 工作台固定为窗口高度，整页不滚动；知识库与概览只在导航下方的内容区滚动，顶部导航与账号菜单保持固定；无常驻侧栏，首页默认进入知识库
- 基于真实接口数据的学习概览和最近更新
- 知识点全宽列表、搜索、状态筛选、详情、创建、编辑和删除
- 桌面并排编辑和实时预览，手机切换编辑／预览
- Markdown、表格、代码、数学公式和 Mermaid 图表
- 未保存内容的站内离开与刷新提醒
- 知识点状态：未开始、学习中、已掌握
- 响应式布局，支持桌面端和移动端窗口

## 测试流程

1. 先启动后端，再启动前端。
2. 打开 `http://localhost:5173/register` 注册账号。
3. 注册成功后默认进入知识库；从受保护页面转入登录／注册时，成功后回到原目标页。
4. 点击“新建知识点”进入独立编辑页，保存后进入详情；可继续编辑、预览和删除。
5. 刷新页面，确认登录状态和知识点仍然存在。
6. 点击退出登录，再访问学习空间，确认会跳转到登录页。

真实的 `backend/.env` 和前端本地 `.env.local` 不要提交到 Git。

## 页面隔离回归

先启动本地前端，再运行 `npm run verify:ui`。脚本使用 Playwright 拦截 `/api/` 请求，测试数据只存在于浏览器测试进程中，不连接真实数据库。执行环境需提供 Playwright 和可用的 Chromium 浏览器；不需要新增应用运行时依赖。

可通过 `PLAYWRIGHT_MODULE` 指定已有 Playwright 模块路径，通过 `BROWSER_EXECUTABLE` 指定已有 Chrome / Edge 可执行文件。`TEST_BASE_URL` 默认 `http://127.0.0.1:5173`，`TEST_ARTIFACTS` 默认仓库中被忽略的 `.tmp/ui-redesign/`，包含截图和 `report.json`。

此回归覆盖三种窗口宽度、登录注册跳转、知识点操作、错误重试、未保存提醒及富文本显示。通过隔离回归不代表真实云端数据库或正式部署已验证。

## 第6课：分类、文件与历史

- 编辑页标题右侧“分类与标签”展开设置：一个分类（最多40字符），最多10个标签（每个20字符），用逗号或顿号分隔。知识库支持分类、标签、状态组合筛选，搜索覆盖标题、正文、分类和标签。
- 知识库“导出备份”下载当前账号的全部知识点 JSON，包含标题、正文、分类、标签、状态、复习标记；不含用户编号、记录编号、时间和版本历史。筛选不限制备份范围。
- 详情“导出 MD”下载标题和 Markdown 正文。Markdown 不保存分类、标签、状态等元数据；完整迁移请用 JSON。
- “导入”支持 `.md`、`.markdown` 和平台 JSON 备份。先显示预览，确认后新增副本。Markdown 第一个一级标题作为标题，缺省使用文件名；正文仍支持公式和 Mermaid。
- 文件最多5MB、最多预览1000条；分批请求，每批最多30条且内容约800KB。标题120字符、正文20000字符。解析或校验失败不写入；部分写入失败保留失败项可重试，同一窗口重试不会重复创建已成功项。重新选择文件视为一次新导入。
- 详情“历史”预览旧版本，点击恢复后再次确认。恢复包含标题、正文、分类、标签、状态、复习标记，并保存为新版本。当前版加最多10个旧版本，旧版本总大小最多300000字节，超出时淘汰最旧版本；删除知识点同时删除其历史。
- 多页面保存发生版本冲突会提示重新打开；失败保留表单输入。旧数据无需批量迁移，首次实际修改开始记录历史。

纯文件逻辑验证：在 `front/` 执行 `npm run test:transfer`。第6课后端隔离验证：在 `backend/` 执行 `npm run test:lesson6`。真实云端和页面验证范围见变更记录。

## 第7课：录音复述（代码已接入，待手动验收）

从知识点详情点击“录音复述”，进入 `/knowledge/:id/record`。顶部与底部操作区固定；原文、复述输入框、历史各自滚动，手机切换“原文参考 / 录音与复述”。录音支持开始、暂停、继续、停止，按有效录音计时，59秒自动停止。浏览器后台节流或设备异常仍可能导致停止延迟，实际超过60秒的音频会提示重新录制。

停止后可回放，浏览器将实际录音解码并重采样为16kHz、单声道、16位PCM WAV。转换失败不会用修改文件后缀代替转换；仍可回放原录音检查。需要支持 MediaRecorder 和 Web Audio 的现代浏览器，使用 HTTPS 或本机 localhost/127.0.0.1；局域网普通HTTP地址不支持麦克风录音。

“转成文字”才会上传音频给后端，再由后端发送给百度识别。本站不持久化音频；退出或刷新后录音不保留。识别失败保留本次录音，可手动重试；不自动重试，以免重复消耗识别额度。转录结果可修改，“保存复述”仅存文字、时长和时间。历史展示最近20条，旧记录仍在数据库，不是只保留20条。保存超时后原样重试复用保存标识；修改文字或重新录制视为新的保存。

后端必须配置百度凭据并创建 `feynman_attempts` 集合，步骤见 [后端说明](../docs/技术文档/backend-README.md#第7课录音识别与复述保存)。未配置时仍可录音和回放，转录提示503；未建集合时复述历史/保存以及知识点关联删除会提示数据库配置问题。

录音、转换、识别或保存过程中离开页面会提醒；确认离开后释放麦克风与本地资源、取消请求。录音页退出账号也先经过离开提醒，取消不会清除登录态。已保存文字可在刷新后重新读取；录音本身不会恢复。

按用户要求，本轮未编写或运行测试、未构建、未操作浏览器验证。人工验收清单见第7课变更记录。

## 第8课：AI评价与复习（代码已接入，待手动验收）

- 本次文字点击“保存并AI评价”：先按第7课方式保存，再打开评价弹窗；也可从历史的“AI评价 / 查看评价”进入。首次评价在弹窗说明数据去向后点击“开始AI评价”才发起调用。弹窗挂载和刷新读取已有结果只GET，不自动产生付费调用。
- 后端读取已保存复述及知识点原文，原文与文字会发送至已配置的 DeepSeek 服务。当前仅调用 DeepSeek，不会切换其他供应商；润色不会覆盖原始文字，不修改知识点正文。
- 弹窗显示原始复述、润色、优点、问题、建议、分数、来源模型与时间。成功评价缓存于该复述中，重复操作不再次请求模型；改写文字再保存为新复述才获得新的评价。
- 低于60分会尝试将知识点加入复习；60分不自动标记。高分不取消已有复习。原文变化时不自动修改复习状态，页面提示评价基于旧原文。评价成功而标记失败时可补做，无需再次调用模型。已经应用过的自动标记不因再次查看而强制恢复。
- 概览有待复习数量、独立待复习列表和最近更新标记；“AI服务记录”折叠区仅显示当前用户调用次数、成功率和平均耗时。指标从本功能启用后开始累计，取消单独统计，不纳入成功率/平均耗时；统计读取失败不显示虚构数字。
- 关闭弹窗或离开页面会取消等待中的请求，已经发出的模型调用可能已计费。识别/保存复述与AI评价的失败分别提示，不丢弃已保存文字。
- 数据库保存失败的模型结果仅在当前后端进程内暂存10分钟，可点击重试保存；后端重启、多进程切换或暂存过期会丢失该暂存，届时再评价可能重新计费。不要把这个机制当成外部调用的严格exactly-once保证。

在 `backend/.env` 配置 `DEEPSEEK_API_KEY` 和 `DEEPSEEK_MODEL` 后手动重启后端。硅基流动、OpenRouter和千帆的环境变量暂时保留，但当前代码不读取或调用它们。无需新增CloudBase集合：评价放在feynman_attempts，统计放在users。代码与人工验收清单见第8课变更记录。本轮未新增/运行测试、未构建、未操作浏览器验证。
